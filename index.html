    Google Cloud Vision

    Google's OCR reads Malayalam, Hindi, Tamil, Telugu, Kannada, Bengali, Arabic and 50+ more languages, and handles photos, columns and mixed scripts well. Images are sent to Google to be read.

    1. Open Cloud Vision API in Google Cloud and press Enable (needs a project with billing turned on).
    2. Go to Credentials → Create credentials → API key.
    3. Recommended: restrict the key to the Cloud Vision API, and to your website's address.

    Pricing: the first 1,000 pages each month are free, then about US$1.50 per 1,000 pages (check Google's current pricing). The key stays in this browser and is sent only to Google.
